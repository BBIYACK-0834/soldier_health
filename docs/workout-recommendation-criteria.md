# 운동 추천 기준

## 조사 요약

운동 추천은 `목표`, `운동 가능 일수`, `숙련도`, `보유 장비`, `군 체력시험 특이성`을 순서대로 적용하되, 분할 선택의 최종 결정은 사용자에게 맡긴다. 기본 원칙은 다음과 같다.

1. **안전/지속성 우선**: 건강 상태와 현재 신체활동 수준이 다르므로 고강도 운동 전에는 준비도와 체력 수준을 확인하고, 강도는 점진적으로 올린다.
2. **주간 최소 기준 충족**: 성인은 유산소와 근력운동을 함께 수행해야 하며, 근력운동은 주요 근육군을 주 2일 이상 자극하는 것을 기본값으로 둔다.
3. **목표별 자극 분리**: 벌크업은 중량/근비대 볼륨, 감량은 근력 유지와 유산소/컨디셔닝, 유지/일반 체력은 전신 균형과 지속성, 특급전사/체력시험은 실제 평가 종목 특이성을 우선한다.
4. **숙련도별 진행**: 초보자는 전신·기본 동작·낮은 세트 수를 우선하고, 숙련도가 올라갈수록 분할, 운동 수, 세트 수, 고중량/고강도 비율을 늘리는 방향을 추천한다.
5. **사용자 선택 우선**: 숙련도별 분할은 권장안으로만 제시하고, 실제 주 운동 횟수와 분할은 사용자가 선택한 값을 따른다.
6. **장비 매칭**: 보유 장비가 있는 경우 해당 장비 운동을 우선하되, 장비가 없으면 맨몸/밴드 대체 운동으로 주요 움직임 패턴을 채운다.

## 조건별 추천 기준

| 조건 | 추천 기준 | 이유 |
| --- | --- | --- |
| 주 1~2회 가능 | 전신 루틴. 스쿼트/힌지/푸시/풀/코어를 한 번에 배치 | 빈도가 낮으면 분할보다 주요 근육을 매번 자극하는 편이 효율적 |
| 주 3회 가능 | 전신 A/B/C 순환. 하체·가슴·등·어깨·코어를 주간에 반복 | 주요 근육군을 주 2회 이상 자극하기 쉬움 |
| 주 4회 가능 | 상체 Push / 하체 Quad / 상체 Pull / 하체 Posterior | 회복일을 확보하면서 부위별 볼륨을 늘릴 수 있음 |
| 주 5~6회 가능 | 등/가슴/어깨/팔/하체 세분화 + 코어/컨디셔닝 보강 | 숙련자에게 필요한 부위별 볼륨과 장비 활용도를 높임 |
| BEGINNER | 2세트 중심, Medium 이하 강도, 워밍업/가동성/맨몸·머신 우선 | 동작 학습과 부상 위험 관리가 우선 |
| NOVICE | 3세트 중심, 복합운동과 보조운동 균형 | 기본 동작이 가능하므로 점진적 과부하를 적용 |
| INTERMEDIATE | 3~4세트, 고중량/컨디셔닝 비중 확대 | 회복 가능한 범위에서 주간 볼륨과 강도를 늘림 |
| BULK | 복합 고중량 운동 우선, HEAVY 5~8회, MODERATE 8~12회, 120~180초 휴식 | 근력과 근비대 목적에 맞게 중량과 충분한 휴식을 확보 |
| CUT | 근력운동은 유지하고 15~20분 유산소 피니셔 또는 컨디셔닝 추가 | 감량 중 근손실을 줄이고 에너지 소비를 늘림 |
| MAINTAIN / GENERAL_FITNESS | 8~15회, 전신 균형, Medium 강도 | 건강 유지와 장기 지속성을 우선 |
| FITNESS_TEST | 3km 달리기, 푸시업, 윗몸일으키기, 코어/인터벌을 우선 | 평가 종목은 종목 특이성이 가장 중요 |
| 장비 부족 | 맨몸/밴드/기본 코어 운동으로 대체 | 전통적인 헬스장 장비가 없어도 저항운동 효과를 낼 수 있음 |

## 앱 적용 방식

- `WorkoutRecommendationService`는 먼저 사용자가 직접 고른 `workoutDaysPerWeek`를 존중하고, `workoutLevel`, `goalType`, 보유 장비를 함께 읽는다.
- 목표가 `FITNESS_TEST`이면 분할 루틴보다 3km 달리기, 푸시업, 윗몸일으키기 중심 루틴을 즉시 반환한다.
- 그 외 목표는 사용자가 선택한 운동 가능 일수에 따라 루틴 템플릿을 고른 뒤, 보유 장비와 숙련도 조건을 만족하는 후보만 남긴다.
- 후보 운동은 목표별 가중치, 루틴의 선호 움직임 패턴, 장비 일치 여부로 점수화하고, 같은 패턴에 쏠리지 않도록 균형 있게 선택한다.
- 응답의 `note`에는 어떤 기준이 적용됐는지와 분할 결정은 사용자 선택이라는 점을 요약해 프론트에서 사용자가 추천 이유를 바로 볼 수 있게 한다.

## 참고한 근거

- CDC/ACSM/HHS 계열 가이드: 성인은 중강도 유산소 150~300분 또는 고강도 75~150분에 해당하는 활동과, 주요 근육군을 포함한 근력운동 주 2일 이상을 기본 권고로 둔다.
- ACSM 2026 저항운동 입장문 요약: 건강한 성인은 복잡한 프로그램보다 지속 가능한 저항운동 참여가 중요하고, 근력은 80% 1RM 수준의 무거운 부하 2~3세트, 근비대는 근육군당 주간 약 10세트를 기준으로 조정한다.
- CDC 근력운동 설명: 근력운동은 도움 없이 다음 반복이 어려운 수준까지 8~12회 반복하고, 더 큰 효과를 위해 2~3세트까지 늘릴 수 있다.
- AHA 심박 기준: 중강도 유산소는 대략 최대심박의 50~70%, 고강도는 70~85%를 참고한다.
- NSCA 빈도 가이드: 초보자는 전신 저항운동 주 2~3일이 적절하며, 스트레스와 회복 상태에 따라 빈도를 조절한다.
- 군 체력 목표: 특급전사/전투 체력 목표는 평가 종목인 달리기, 푸시업, 윗몸일으키기, 전투 체력 요소를 직접 훈련하는 종목 특이성이 중요하다.
